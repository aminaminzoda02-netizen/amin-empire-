# AMIN EMPIRE — Mobile App Guide

`public/mobile.html` is a mobile-first app shell using the same backend/API as the website.

For a real Android/iOS app later:
- Android: wrap the web app with a trusted WebView/TWA or build a native client.
- iOS: use a native client or approved web-app wrapper.
- Keep authentication, payment, XP, certificates and business statistics on the server.
- Never embed card data or provider secrets in the mobile client.

This starter is for development and testing, not an app-store submission.
